| `api/test/manual/tts-cache/CR16102809-TTS缓存验收.py` | 新增验收脚本 |

## 缓存目录

`storage/tts_cache/`，对应宿主机 `docker/volumes/app/storage/tts_cache/`

- 已被 `.gitignore` 的 `docker/volumes/` 覆盖，**不进版本库**
- **不要**把该目录挂到 nginx 静态路径（会绕过鉴权，见风险 R-05）

## 参数调整

`audio_service.py` 顶部：

| 常量 | 现值 | 说明 |
|---|---|---|
| `TTS_CACHE_TTL_SECONDS` | 7 天 | 过期文件在下次访问时被删除 |
| `TTS_CACHE_MAX_BYTES` | 20MB | 超出的结果不写缓存（约 7~8 分钟音频） |

## 手工清理（兜底）

```bash
# 删除 7 天前的缓存
find docker/volumes/app/storage/tts_cache -type f -mtime +7 -delete

# 全部清空（下次访问会重新合成）
rm -rf docker/volumes/app/storage/tts_cache/*
```

## 回滚

```bash
git revert <commit> && docker compose build llmops-api && docker compose up -d llmops-api
docker compose restart llmops-nginx
```

缓存目录留着无害（不会被旧代码读取），也可以直接删。
