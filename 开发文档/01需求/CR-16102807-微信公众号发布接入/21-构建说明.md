## 回滚

```bash

docker exec llmops-api flask db downgrade -1

# 2. 移除代码：新增的 7 个文件 + router/__init__ 注册 + app.py 的 property
# 3. 移除依赖：requirements 里的 wechatpy；Dockerfile 的 TIKTOKEN_CACHE_DIR

docker compose restart llmops-nginx
```

## 配置（部署侧必看）

```bash
# docker/.env
SERVICE_IP=1.2.3.4                    # 公网 IP，展示给用户填到公众号后台
SERVICE_API_PREFIX=http://1.2.3.4/api  # 必须是微信服务器能访问到的地址
```

**若这两项仍是 `localhost`，公众号后台点「提交」一定报「请求 URL 超时」**。前端已对这种情况显示黄色警告。
