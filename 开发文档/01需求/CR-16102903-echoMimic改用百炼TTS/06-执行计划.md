# 06-执行计划 · echoMimic 改用百炼 TTS

## 1. 目标与非目标

- **目标**：`echoMimic/webgui.py` 的「转换为语音」改走阿里百炼，失败弹窗可读，配置项与依赖清单自洽。
- **非目标**：不动 `process_video` / 模型加载 / 参数面板 / 界面布局；不动主平台 `api` `ui`；不重建任何镜像；不跑数字人视频生成。

## 2. 改动清单（文件级）

| # | 文件 | 改什么 |
|---|---|---|
| 1 | `echoMimic/webgui.py` | ① 删 `from openai import OpenAI`，加 `import base64`；② `text_to_speech()` 整段替换为百炼原生实现（url/base64 双分支、`mkdir(parents=True)`、返回 `str`、失败 `gr.Error`、空文案拦截）；③ `fetch_data()` 加 `timeout=120`；④ 三处 `.to("cuda"` 改用 `device` 变量（`vae` / `face_locator` / `pipe`），`face_mask_tensor` 同理 |
| 2 | `echoMimic/.env.example` | OpenAI 段替换为百炼段（`DASHSCOPE_API_KEY` / `DASHSCOPE_TTS_URL` / `TTS_MODEL` / `TTS_VOICE`），注明「百炼不是 OpenAI 兼容 `audio/speech`」 |
| 3 | `echoMimic/.env` | 同上（本地文件，已被 `.gitignore:32` 忽略）；`LLMOPS_*` 三键保持原值不动 |
| 4 | `echoMimic/requirements.txt` | 删 `openai`，加 `requests`（代码直接 import 却未声明） |

## 3. 执行步骤（每步都能验）

| 步 | 动作 | 怎么验 |
|---|---|---|
| S1 | 改 `webgui.py` 的 TTS 与 import | `python -m py_compile echoMimic/webgui.py` 无输出 |
| S2 | 真实调用 `text_to_speech('你好…')` | 返回 `storage/audio/*.mp3` 且 >1 KB，`ffprobe` 认出 mp3 |
| S3 | 空文案分支 | 抛 `gr.Error`，信息含「为空」，且**未**发出网络请求 |
| S4 | 错误 key 分支 | 抛 `gr.Error`，信息含 `401`，服务进程不崩 |
| S5 | 配置对齐 | 源码/模板中 `tts-1`、`alloy`、`OPENAI_` 零命中；模板键集合 = 代码 `os.getenv` 键集合 |
| S6 | 依赖对齐 | `requirements.txt` 有 `requests`、无 `openai` |
| S7 | 视频链路零改动复核 | `git diff` 中 `process_video` 与事件绑定段落不出现 |

> 验证方式说明：`webgui.py` 在 import 期就加载 7 份模型权重（仓库内缺失），**整站无法启动**。
> 因此 S2–S4 用「AST 抽取 `text_to_speech` 函数源码 → 在注入 `os/uuid/Path/requests/base64/gr` 的命名空间里 exec」
> 的方式调用，跑的是**文件里的真实函数体**，不是另写一份副本。
