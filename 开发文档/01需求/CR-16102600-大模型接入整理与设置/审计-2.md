## 2026-10-26 21:17 · 回归缺陷：助手对话 500 `AttributeError: can't set attribute 'embeddings'`

**现象**：`POST /api/assistant-agent/chat` 返回 500，日志：

```
File "/app/api/internal/service/assistant_agent_service.py", line 94, in chat
AttributeError: can't set attribute 'embeddings'
```

**根因（本 CR 自己引入的回归）**：`faiss_service.py::convert_faiss_to_tool` 里为了「让知识库检索跟随设置页最新凭证」写了

```python
self.faiss.embeddings = self.embeddings_service.embeddings   # ✗
```

而 `langchain_community 0.2.19` 的 `FAISS.embeddings` 是**只读 property**（返回 `self._embeddings`，没有 setter）⇒ 赋值直接抛 `AttributeError`。凡是调用辅助 Agent 对话的请求都会在构造检索工具时崩，属于**全站助手功能不可用**级别。

**为什么之前的自测没抓到**：上一轮我验证知识库用的是 `faiss.similarity_search(...)`（直接调底层），而真实链路是 `chat → convert_faiss_to_tool()`——**测的对象不是出问题的那个函数**。

**修复**：

```python
self.faiss._embeddings = self.embeddings_service.embeddings   # ✓ 写底层字段，property 读它
```

**回归验证**（重建镜像 → `up -d llmops-api llmops-celery` → `restart llmops-nginx`）：

| 验证 | 结果 |
|---|---|
| `POST /api/assistant-agent/chat`（经 nginx，真实 JWT） | **200**，SSE 正常流式返回「你好！有什么可以帮你的吗？」，`total_token_count: 464` |
| `convert_faiss_to_tool()` 构造 | `TOOL: dataset_retrieval` 成功 |
| 工具实调（`如何创建 LLM 应用并发布成 WebApp`） | 返回 1665 字符相关接口文档片段 |

**教训（已写入 `构建说明.md` 之外的验证要求）**：验证必须落在**真实调用链的那个函数**上；`similarity_search` 与 `convert_faiss_to_tool` 不是一回事。凡改到 LangChain 第三方对象的内部属性，先确认它是 property 还是普通属性。
