## 1. 用户原话（一字不改）

> @d:\02_Resources\agent全栈项目\LLM-Ops-python\EchoMimic\.env  .env.example

原话只有两个文件引用，没有动词。按「有一个 `.env`、缺一个 `.env.example`」的事实判断为：
**照 `echoMimic/.env` 生成一份可提交的 `.env.example` 模板**。判断依据与备选解释见 `决策记录.md` D1。

## 2. 目标

1. **新人拿到仓库就能配起来**：只读 `.env.example` 就知道要填哪几个变量、每个变量从哪取。
2. **模板里不出现任何真实凭证**：密钥、应用 id 一律占位。
3. **与代码真实读取的变量一致**：不写代码不读的变量，也不漏代码会读的变量。

## 3. 范围

### 3.1 做

- 新增 `echoMimic/.env.example`，覆盖 4 类共 6 个变量 + 1 个可选变量：
  - TTS：`OPENAI_API_KEY`、`OPENAI_API_BASE`（`webgui.py:254-255`）
  - 文案：`LLMOPS_APP_ID`、`LLMOPS_API_KEY`、`LLMOPS_API_BASE`（`webgui.py:218-220`）
  - 可选：`FFMPEG_PATH`（`webgui.py:50`、`infer_audio2vid*.py:34`）

### 3.2 不做

- 不改 `echoMimic/.env`（真实值保持现状）。
- 不改任何 `.py`。
- 不改 `echoMimic/.gitignore`（`.env` 未列入忽略，见 `风险.md` R-01，单独请示）。
- 不把 EchoMimic 接入 `docker/docker-compose.yaml`（它跑在宿主 GPU 上，不经容器）。

## 4. 验收标准

| 编号 | 标准 |
|---|---|
| AC-01 | `echoMimic/.env.example` 存在，UTF-8 无 BOM，纯 `KEY=VALUE` + `#` 注释，可被 `python-dotenv` 直接解析 |
| AC-02 | 模板键集合 = `{OPENAI_API_KEY, OPENAI_API_BASE, LLMOPS_APP_ID, LLMOPS_API_KEY, LLMOPS_API_BASE}`，与 `.env` 键集合完全一致 |
| AC-03 | 模板的**赋值行**（`KEY=VALUE`）不含 `sk-` 开头的串、不含 `llmops-v1/`、不含真实应用 id `8de7c392…`；注释里说明格式允许 |

| AC-05 | `FFMPEG_PATH` 以注释形式给出（可选变量，填了才生效） |
