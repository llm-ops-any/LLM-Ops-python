# CR-16102807 需求：微信公众号发布接入

- **需求性质**：增量
- **来源**：PO 2026-10-28「做公众号那个任务」；缺口识别见 `02缺陷/CR-16102806` 之前的差距比对（原项目 `wechat` 全套未迁）
- **类型**：需求（用户可感知的新能力）

## 一、背景

课程原项目 `imooc-llmops` 支持「把已发布的 Agent 应用接入微信公众号」：用户在公众号里发消息，Agent 异步处理，回复「1」拿结果。本项目完全没有这块（`wechat_service` / `platform_*` / 3 张表全缺）。

## 二、功能需求

### FR-01 应用发布页可配置微信公众号
在「应用详情 → 发布管理」新增「微信公众号」卡片，可填 **AppID / AppSecret / Token** 三项，并展示只读的：
- **服务器地址(URL)**：`{SERVICE_API_PREFIX}/wechat/{app_id}`
- **服务器 IP**：`SERVICE_IP`
- **配置状态**：已配置 / 未配置

### FR-02 状态自动维护
配置状态由后端推导，前端不可直接写：
- 三项齐全 **且** 应用已发布 → `configured`
- 任一项为空 → `unconfigured`
- 应用处于草稿 → 强制 `unconfigured`（草稿不允许对外服务）

### FR-03 微信服务器接入校验（GET）
微信侧保存配置时会发 GET 带 `signature/timestamp/nonce/echostr`：
- 签名校验通过 → **原样返回 `echostr`**
- 签名错误 → 返回明确失败提示

### FR-04 文本消息异步处理
收到 POST 文本消息后：
1. 按 `openid` 找到/创建终端用户（`EndUser` + `WechatEndUser`），并复用其会话
2. 落一条 `Message` 与一条**未推送**的 `WechatMessage`
3. **起子线程**跑 Agent（微信要求 5 秒内响应，同步跑必超时）
4. 立即回复「思考中，请回复"1"获取结果。」

### FR-05 回复「1」拉取结果
- 有未推送结果且答案已生成 → 推送答案，并标记已推送（**不重复推送**）
- 任务仍在处理 → 提示稍后再回复 1
- 任务超时 → 提示超时
- 任务出错 → 提示错误信息

### FR-06 非文本消息拦截
图片/语音等一律回复「该 Agent 目前暂时只支持文本消息。」

### FR-07 前置状态提示
- 应用不存在或未发布 → 「该应用未发布或不存在…」
- 未配置微信公众号 → 「该应用未发布到微信公众号…」

## 三、不做

| # | 不做 | 原因 |
|---|---|---|
| 1 | 公众号菜单、模板消息、客服消息 | 原项目也没有；需要额外权限与产品设计 |
| 2 | 图片/语音消息转多模态输入 | 微信 XML 媒体消息需先下载素材，属独立需求 |
| 3 | 微信客服（企微）中间件路线 | 是另一条通道，与本需求并行存在，不在本次范围 |
| 4 | 多公众号绑定同一应用 | 原项目一对一（`wechat_config.app_id` 唯一索引），保持一致 |

## 四、验收标准

| AC | 内容 | 判定 |
|---|---|---|
| AC-01 | 配置读写接口可用，密钥字段原样回显（原项目行为） | `curl` 读写 |
| AC-02 | 状态联动：三项齐全且已发布 → `configured`；改草稿 → `unconfigured` | 改状态前后各查一次 |
| AC-03 | GET 签名校验通过返回 `echostr`；错误签名返回失败 | 本地构造签名请求 |
| AC-04 | POST 文本消息 → 立即返回「思考中」；Agent 完成后回复「1」拿到答案 | 本地模拟微信 XML |
| AC-05 | 重复回复「1」不重复推送同一条结果 | 连发两次 1 |
| AC-06 | 非文本消息被拦截 | 构造 image 消息 XML |
| AC-07 | 前端发布页能配置并保存，状态即时更新 | 界面走查 |
| AC-08 | 不影响既有功能（SSE、语音、pptx、WebApp） | 回归抽检 |

## 五、验收环境限制（重要）

**真机联调需要公网可访问地址**（微信服务器必须能回调 `http://<公网IP>/api/wechat/<app_id>`）。
当前为本机 Docker + 局域网 IP，**微信侧无法回调**。

因此本 CR 的 AC-01~AC-06 全部用**本地构造的等价请求**验证（协议与微信一致，只是不走微信服务器），AC-07 走界面。
真机联调另需：公网 IP 或内网穿透 + 已认证公众号；这部分**不阻塞代码交付**。
