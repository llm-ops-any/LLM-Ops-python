# CR-16102803 变更说明

> 对项目级事实的影响（交付 / 存储 / 规模）。全局视图由 `汇总.py` 合成到 `_汇总/项目现状.md`。

## 一、交付形态变化

| 项 | 变化 |
|---|---|
| 能力 | 新增「语音能力」：文本转语音（朗读消息）+ 语音转文本（语音输入），**三档引擎可切换** |
| 入口 | 平台设置新增「语音服务」；应用编排新增两个能力开关；AI 消息出现播放按钮；聊天框麦克风按引擎分派 |
| 配置载体 | 新增 `platform_setting` 记录 `name=speech_provider`（**KV 表，无新表、无迁移**） |
| 依赖 | **零新增**（pip / npm 均未变） |
| 镜像 | `llmops-api:0.1.0`、`llmops-ui:0.1.0` 重建 |
| 数据库 | 无表结构变更 |

## 二、存储与凭证

- 阿里百炼 API Key 以 **Fernet 密文**存 `platform_setting.value` 的 `dashscope_api_key_cipher` 字段，主密钥由既有 `JWT_SECRET_KEY` 派生（复用 `lib/secret.py`）。
- ⚠️ **换 `JWT_SECRET_KEY` 会让该密文失效**，表现为 `source=invalid`，需重新填写 Key。
- 本项目 `docker/.env` 的 `DASHSCOPE_API_KEY` 仍为空，**不影响**：以数据库配置优先，环境变量只作兜底。

## 三、外部服务依赖（新增）

| 服务 | 用途 | 计费 |
|---|---|---|
| 阿里百炼 `qwen3.8-omni-flash-realtime` | Omni 档 TTS（Realtime WebSocket） | 音频输入 6 元/百万 token、输出 12 元/百万 token（≈0.9 分/分钟音频） |
| 阿里百炼 `cosyvoice-v3-flash` | DashScope 档 TTS | **1 元/万字符**（含 1 万字符免费额度，90 天） |
| 阿里百炼 `paraformer-realtime-v2` | DashScope 档 ASR | 按音频时长 |

> 与既有「中转平台无任何语音能力」的事实并列：语音能力**必须**走阿里百炼，不能用 `token.uino.com`。

## 五、行为变化（对既有用户可见）

1. 消息气泡右侧多了一个播放按钮，**仅当该应用开启「文本转语音」时出现**，默认关闭 ⇒ 未开启的用户无感知。
2. 聊天框麦克风行为随引擎变化：默认（`browser`）与改造前**完全一致**。
3. 设置弹窗多一个「语音服务」菜单项。
