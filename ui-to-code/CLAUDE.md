本目录是 **LLM-Ops-python 的子项目**。AIDLC 档案在**仓库根** `../开发文档/`（2026-10-28 起统一维护，
见 `../开发文档/03技术债/CR-16102802-开发文档统一到根/`），**本目录没有自己的 `开发文档/`**。

进目录后按顺序读：

2. `../AGENTS.md` —— 全仓库「一律先走 AIDLC」

4. `../开发文档/00规则/项目概述.md` 第 11 节 —— 子项目骨架
5. `../开发文档/00规则/开发规范.md` 第十章 —— TS / Next.js 侧写作规矩

> 硬规则不变：任何需求 / 改动 / 排查先进 `../开发文档/<类型目录>/CR-XXXX/`，**不得直接产出代码或部署产物**。
> 规则细则见项目根 `AGENTS.md`；宿主未加载 aidlc 技能时，读 `../开发文档/04技能/aidlc/SKILL.md`。
