# CR-16102807 变更说明

## 一、项目级事实变化

| 维度 | 变化 |
|---|---|
| 新能力 | 应用可发布到微信公众号（订阅号/服务号），支持文本问答与「回复 1 取结果」 |
| 新增依赖 | `wechatpy==1.8.18`（+ 传递依赖 `optionaldict==0.1.2`） |
| 数据库 | **新增 3 张表**：`wechat_config` / `wechat_end_user` / `wechat_message`；迁移 `9c4e2a1b7d30` |
| 新增接口 | `GET/POST /platform/<app_id>/wechat-config`、`GET/POST /wechat/<app_id>` |
| 新增环境变量 | `SERVICE_IP`、`SERVICE_API_PREFIX` |
| 镜像 | 新增 `TIKTOKEN_CACHE_DIR`，预置 cl100k_base 编码文件（1.7MB） |
| 前端 | 应用发布页新增微信公众号渠道卡片与配置模态窗 |

## 二、运维影响

- **部署后必须 `restart llmops-nginx`**：`up -d` 会改变容器 IP，不重启会 502。
- **`/wechat/*` 是公网入口**，目前无鉴权，靠「应用已发布 + 凭证齐全」把关；若要限流需另配 nginx。
- **tiktoken 不再联网**：`TIKTOKEN_CACHE_DIR` 指向镜像内目录，跨重启有效。**好处覆盖全项目**，不只是微信。
- 新增 3 张表**无历史数据**，回滚直接 `downgrade -1`。

## 三、与既有 CR 的关系

| CR | 关系 |
|---|---|
| `CR-16102701` 图片多模态 | **有冲突点已处理**：本项目 `Message` 用 `attachments`，不是原项目的 `image_urls`（D-06） |
| `CR-16102803` 语音 | 互不影响；但**安全口径不一致**（语音 Key 加密掩码 vs 微信 Secret 明文），见 D-04 |
| `CR-16102804` pptx 工具 | 互不影响；微信里若触发工具调用会走同一 Agent 链路 |
| `CR-16102806` 静默超时 | 微信走的是**非流式 `invoke`**，不经过 SSE 队列，静默超时保护不适用 |
