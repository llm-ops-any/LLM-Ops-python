## 本子项目速览

- Next.js 15 + React 19 + TS 5 + Tailwind 4，单页面 `/` + 两个 Route Handler（`/api/chat`、`/api/upload/image`）
- dev：`npm run dev` → `localhost:3000`；容器：`docker compose up -d --build` → `localhost:3001`
- 凭证在 `.env`（模板 `.env.example`，**`.env` 不入库**）；浏览器只调本项目 `/api/*`
- 它消费本平台开放 API（`../` 下的 LLMOps），图片先传 COS 拿公网 URL，再以平台 `files` 传给模型
