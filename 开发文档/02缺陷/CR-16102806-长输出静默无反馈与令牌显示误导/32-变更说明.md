# CR-16102806 变更说明

## 一、项目级事实变化

| 维度 | 变化 |
|---|---|
| 依赖 | **无**（`requirements.txt` / `package.json` 均未改） |
| 数据库 | **无**（无迁移、无字段） |
| 接口契约 | **无**（SSE 事件类型与字段完全不变） |
| 新增环境变量 | `AGENT_SILENT_TIMEOUT`（默认 300，`0` 表示关闭） |
| 新增模块 | `ui/src/hooks/use-stream-idle.ts` |
| 运行行为 | 智能体连续 300 秒无内容块 → 下发 `error` 事件并结束流（原为等满 600 秒发 `timeout`） |
| 界面行为 | 静默 >20 秒显示「正在生成，已等待 N 秒」；Token 流式中显示「统计中」 |

## 二、运维影响

- **部署无需额外动作**：`docker compose up -d` 即生效，配置项已在公共锚点里带默认值。
- **监控**：新增的 `error` 事件会写进 `message.status`，可通过日志关键词 `判定上游链路中断` 检索静默失败频率（用于判断上游是否持续恶化）。
- **可关闭**：`AGENT_SILENT_TIMEOUT=0` 可退回旧行为，用于排查时排除误判可能。

| CR | 关系 |
