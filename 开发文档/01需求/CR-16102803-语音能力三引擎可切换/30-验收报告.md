## 四、已知边界（不阻塞，但需知情）

1. **WebApp 页无朗读按钮**：发布出去的应用页面目前不能朗读。要补需让 `/web-apps/<token>` 返回 `text_to_speech`，属接口契约变更，建议单独开 CR。
2. **首页（辅助 Agent）消息不能朗读**：`message_to_audio` 只支持应用会话（`debugger` / `web_app`），辅助 Agent 消息会被判「应用未开启 TTS」。
3. **保存生效非瞬时**：4 个 gunicorn worker 各自缓存 5 秒，实测切换引擎后立即调用可能仍走旧引擎，约 5~10 秒收敛。
4. **TTS 无缓存**：同一条消息点两次会重新合成两次、计费两次（R-03，本 CR 未做）。
5. **录音需 HTTPS 或 localhost**：当前 nginx 为 IP + HTTP 直服，局域网 IP 访问时录音会失败并提示原因（R-08）。
6. **`cosyvoice-v3.5-flash` 从未成功**：按你要求后续不再测试。
