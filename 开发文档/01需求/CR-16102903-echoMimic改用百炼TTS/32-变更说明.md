# 32-变更说明 · echoMimic 改用百炼 TTS

## 1. 改变了什么（对外可见）

| 面 | 之前 | 之后 |
|---|---|---|
| 「转换为语音」的推理来源 | OpenAI `tts-1` @ `https://api.nekoapi.com/v1`（该中转站无此模型） | 阿里百炼原生 `audio/tts/SpeechSynthesizer` |
| 缺省模型 / 音色 | `tts-1` / `alloy` | `qwen-audio-3.1-tts-flash` / `longanhuan_v3.1` |
| 失败时界面表现 | 文案框旁无反应，服务端 `OSError`（字符串被当路径） | 弹窗显示百炼原始错误（如 `百炼返回 401：InvalidApiKey`） |
| 空文案 | 仍发一次请求 | 直接弹窗，不发请求 |
| 配置键 | `OPENAI_API_KEY` / `OPENAI_API_BASE` | `DASHSCOPE_API_KEY` / `DASHSCOPE_TTS_URL` / `TTS_MODEL` / `TTS_VOICE` |

## 2. 文件清单

| 文件 | 性质 | 说明 |
|---|---|---|
| `echoMimic/webgui.py` | 代码 | TTS 函数整段替换；`import base64`；删 `from openai import OpenAI`；`fetch_data` 补 `timeout=120` + 缺配置提示；4 处 `.to("cuda")` 改用 `device` |
| `echoMimic/.env.example` | 配置模板 | OpenAI 段 → 百炼段，注明百炼不是 OpenAI 兼容 `audio/speech` |
| `echoMimic/.env` | 本地配置（**不入库**） | 同上；`LLMOPS_*` 三键保持原值 |
| `echoMimic/requirements.txt` | 依赖 | 删 `openai`，补 `requests` |

## 3. 对项目级事实的影响

- **依赖面**：`echoMimic` 运行时不再需要 `openai` SDK；`requests` 由「隐式（gradio 传递依赖）」变为**显式声明**。
- **账号面**：`echoMimic` 与 `gradio-demo` 现在共用同一个百炼账号与同一支可用模型（`qwen-audio-3.1-tts-flash`）。
  两支 TTS 会共享该模型额度 —— 演示与数字人同时压测时可能互相挤占。
- **主平台面**：`api/` `ui/` 与镜像**零改动**，无需重建；主平台的语音能力（`CR-16102803` 三引擎）与本 CR 无关。
- **数据面**：无迁移、无库结构变化。生成的音频仍落 `echoMimic/storage/audio/`（无清理策略，与改动前一致）。

## 4. 回退办法

```bash
git checkout -- echoMimic/webgui.py echoMimic/requirements.txt echoMimic/.env.example
# .env 需手工改回（不入库）；改造前的备份在 echoMimic/.env.bak
```
