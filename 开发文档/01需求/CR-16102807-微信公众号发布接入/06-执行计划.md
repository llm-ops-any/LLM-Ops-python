## 三、验收方法（本地等价请求）

微信协议只有两种请求，本地 verbatim 构造即可，不需要公网：

```bash
# GET 验签：signature = sha1(sort(token, timestamp, nonce))
curl "http://localhost/api/wechat/<app_id>?signature=...&timestamp=...&nonce=...&echostr=hello"
# 期望：原样返回 hello

# POST 文本消息：微信 XML
curl -X POST http://localhost/api/wechat/<app_id> \
  -H "Content-Type: text/xml" \
  -d '<xml><ToUserName><![CDATA[gh_xxx]]></ToUserName><FromUserName><![CDATA[openid_test]]></FromUserName><CreateTime>1700000000</CreateTime><MsgType><![CDATA[text]]></MsgType><Content><![CDATA[你好]]></Content><MsgId>123</MsgId></xml>'
# 期望：<xml>...<Content><![CDATA[思考中，请回复“1”获取结果。]]></Content>...</xml>
```
