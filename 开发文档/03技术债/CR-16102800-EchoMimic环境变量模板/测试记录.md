## 1. 键集合一致性（AC-02）

```powershell
cd echoMimic
$keys=@(); Get-Content .env -Encoding UTF8 | % { if ($_ -match '^\s*([A-Za-z_][A-Za-z0-9_]*)=') { $keys += $Matches[1] } }
$ex=@();   Get-Content .env.example -Encoding UTF8 | % { if ($_ -match '^\s*([A-Za-z_][A-Za-z0-9_]*)=') { $ex += $Matches[1] } }
Compare-Object $keys $ex
```

结果：

```
env(5) : OPENAI_API_KEY,OPENAI_API_BASE,LLMOPS_APP_ID,LLMOPS_API_KEY,LLMOPS_API_BASE
exa(5) : OPENAI_API_KEY,OPENAI_API_BASE,LLMOPS_APP_ID,LLMOPS_API_KEY,LLMOPS_API_BASE
diff:
```

⇒ **通过**，键集合完全相同（`FFMPEG_PATH` 在 `.env` 中本就没有，模板里以注释给出）。

> 注：首轮校验用 `Get-Content` 默认编码读 UTF-8 文件，中文行被按 ANSI 解码后吞掉换行，导致只解析出 1 个键——
> **是校验脚本的问题，不是文件的问题**；加 `-Encoding UTF8` 后恢复正常。
