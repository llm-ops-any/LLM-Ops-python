## 1. 用户原话（一字不改）

> 把依赖的镜像打包一份放到这个目录下吧，在线下载太慢了，我别的电脑需要装环境

（`@docker` ⇒ 目标目录是 `docker/`）

## 2. 目标

1. **换机不再依赖公网拉镜像**：把 `docker-compose.yaml` 依赖的镜像导出为本地 tar，拷到新机器
   `docker load` 后直接 `docker compose up -d` 即可起服务，不需要 `docker pull`。
2. **清单不手抄、不漂移**：导出清单由 `docker compose config --images` 现场生成（去重），
   以后在 compose 里换镜像版本，重跑脚本即可，不靠人肉维护第二份列表。
3. **可校验、可复现**：产出 SHA256 校验清单 + 导出/导入脚本 + 一页说明；包按「应用镜像 / 第三方镜像」分组，
   单个 tar 控制在 ~2.4 GB 以内，便于用 U 盘/网盘分批传。

## 3. 范围

### 3.1 做

- 新建 `docker/offline-images/`，产出：
  - `llmops-app-0.1.0.tar`（`llmops-api:0.1.0` + `llmops-ui:0.1.0`）
  - `llmops-thirdparty-20261114.tar`（`redis:6-alpine`、`postgres:15-alpine`、`semitechnologies/weaviate:1.28.4`、`nginx:latest`）
  - `SHA256SUMS.txt`（`Get-FileHash` 生成，导入前可核对）
  - `导出镜像.ps1` / `导入镜像.ps1`（在 `docker/` 下执行，清单动态取自 compose）
  - `README.md`（另一台机从零到起的完整步骤）
- `.gitignore` 排除 `docker/offline-images/*.tar`（体积 GB 级，不进版本库）。
- `开发文档/00规则/部署规范.md` 新增「离线镜像（换机 / 无网环境）」小节，指向本目录脚本。

### 3.2 不做

- **不导出构建期基础镜像**（`python:3.10-slim-bookworm`、`node:20`、`nginx:alpine`）：本机 Docker 里没有，
  导不出来（api / ui 镜像已构建完成，运行不需要它们）。另一台机若要 `--build` 重建，仍需联网拉基础镜像 ⇒ 登记为遗留 L-01。
- **不打包 `volumes/` 数据**（db / redis / weaviate 落盘数据）：业务数据走 `CR-16111409` 的
  `docker/postgres/llmops_data.sql`，两者互补，不重复。
- 不含 `ui-to-code:0.1.0`（子项目独立 compose，不在 `docker/docker-compose.yaml` 内）。
- 不改 `docker-compose.yaml`、Dockerfile、任何业务代码；不启停任何容器。
- 不压缩 tar（`docker save` 原始 tar；压缩收益有限且解压多一步，见 `决策记录.md` D-02）。
