# 工具手册（scripts/）

> 本文件是 `SKILL.md` §6 的**展开**：每个脚本的完整参数、行为、坑都在这里。
> 常驻只记「有哪些工具、各自干什么」；要跑某个脚本、或它报错了，再翻这里。

## 6. 工具（`scripts/`）

九件工具（八个脚本 + 一组 git 钩子；**跟着技能走，项目里不用另建 `工具/`**）：

| 脚本 | 作用 |
|---|---|
| `scripts/初始化.py` | **新项目第一件事**：建六个编号目录 + 五份规则文件（整份复制模板）+ 状态快照 + 技能副本 + 入口锚点 + git 钩子；`--entry claude` 只写 CLAUDE.md、不碰 AGENTS.md。已有项目补人用 `--refresh-team`：只追加，**已有人编号一律不动**（人编号是 CR 号首位，重排等于让历史 CR 对不上人） |
| `scripts/汇总.py` | 扫各 `<类型目录>/CR-<8位号>/*` 分片，重建 `_汇总/` 下 9 个视图（状态/需求索引/当前需求全貌/技术设计/运维/项目现状/决策记录/风险与资源/审计）+ **`看板.html`**（按人 / 时间 / 阶段 / 类型筛选的单文件页面，见 `_board.py`）；加 `--site` 连文档站一起出。**看板带生成时间，不参与 `--check` 比对** |
| `scripts/安装钩子.py` | 设 `core.hooksPath` 指向 `scripts/hooks/`；补 `.gitattributes` 的 LF 保护与 `.gitignore` 的 `_汇总/` 排除 |
| `scripts/自检.py` | 体检 18 类（完整清单见脚本 docstring）：锚点 / 副本位置 / **版本** / 钩子 / `.gitattributes` / 布局 / **规则文件齐全** / 规则文件瘦身 / 生成物 / 编号 / 基线 / 执行计划 / 前置资源 / 风险 / 死规则 / 孤儿 CR / 页面 / CR 时间。带 `--fix` / `--quiet` / `--status` |
| `scripts/自测.py` | **改完脚本先跑它**：临时目录里跑「初始化 → 建 CR → 汇总 → 自检 → 迁移」最小闭环，把「脚本改坏了」和「项目数据有问题」分开。`-v` 打印子命令输出 |
| `scripts/预览.py` | 生成 `_汇总/index.html` + `_sidebar.md` + `vendor/` + `docs/` 快照（自包含文档站，**不连 CDN**）；不加 `--no-serve` 才起本地服务 |
| `scripts/接管-openspec.py` | **存量 OpenSpec 项目专用**：把 `openspec/changes`（含 archive）+ `openspec/specs` 迁成 CR 目录。默认预演，`--write` 才建；幂等；**不修改 `openspec/` 一个字节** |
| `scripts/迁移-编号.py` | **老项目专用**：给 CR 目录补文件编号（`需求.md` → `01-需求.md`、`设计/` → `08-技术设计/08-1-…`）。默认预演，`--write` 才动手；幂等、整条 CR 要么全改要么不改 |
| `scripts/hooks/` | `post-merge` / `post-commit`（父提交数=2）/ `post-rewrite` + `_summary.sh` |

**钩子只做两件事**：重建 `_汇总/` 视图；若 `团队配置.md` 里声明了 `- 构建命令：xxx`，再执行它。
「没声明」的判定与 `自检.py` 一致：**这一行后面必须真空**；写 `（留空）`、`留空`、`不构建`、`无`、`未……` 都算没声明
（钩子会跳过，不会报假失败）。**`仅静态` 档位必须留空** —— 该档位不执行任何脚本命令，填了就是偷偷跑构建。

> 为什么构建命令由项目声明、技能不写死：AIDLC 适用于前端 / 后端 / CLI / 纯文档各种项目，
> 构建可能是 `npm run build`、`cargo build`、`make`，也可能根本不存在。**技能不猜，项目说做什么就做什么。**
> 拼装型项目（产物由源码生成）**应该**配这一行 —— 否则 git 会把产物"自动合并"成半对半错的内容，
> 而且不报冲突（2026-10-22 实测：两条 CR 分叉合并后，产物与重建结果差 362 行，`git merge` 却说成功）。

**改脚本的规矩**：改完先跑 `自测.py`（技能自证），再跑目标项目的 `自检.py`（落地核对）。两步都绿才算改完 —— 不拿真实项目当测试环境。
