# CR-16102804 变更说明

## 一、能力变化

| 项 | 变化 |
|---|---|
| 内置工具 | 从 7 个 provider 增到 **8 个**：新增 `pptx`（PPT工具包），工具 `markdown_to_pptx` |
| 用户可见 | 插件广场/应用编排里可勾选「PPT工具包」；对话中模型可把 Markdown 生成 `.pptx` 并返回下载链接 |
| 前端 | **零改动**（插件广场与编排按 provider 动态渲染） |
| 接口 | **零改动**（复用既有 `/builtin-tools`、`/builtin-tools/<provider>/tools/<tool>`、`/builtin-tools/<provider>/icon`） |

## 二、依赖变化（本 CR 是唯一动依赖的一笔）

| 包 | 版本 | 来源 |
|---|---|---|
| `mistune` | 3.1.2 | 直接依赖（Markdown → slide 渲染） |
| `python-pptx` | 1.0.2 | 直接依赖（落 `.pptx` 文件） |
| `pillow` | 11.1.0 | 传递依赖（python-pptx） |
| `xlsxwriter` | 3.2.2 | 传递依赖（python-pptx） |

- `requirements.in` 增加 `mistune`、`python-pptx`（带注释说明用途）；
- `requirements.txt` 按 pip-compile 格式补 4 条 + `# via` 注释，版本与课程原项目一致。

## 三、存储与外部依赖

- 生成的文件上传到**腾讯云 COS**，路径 `builtin-tools/markdown-to-pptx/<uuid>.pptx`，返回 `get_file_url()` 拼出的公网地址。
- 若 COS 未配置，按本项目既有 `CosService` 分支会走本地兜底（与既有上传行为一致）。
- 无新凭证。
