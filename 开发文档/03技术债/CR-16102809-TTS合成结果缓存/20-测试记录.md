## 二、关键用例说明

### AC-01 / AC-02 命中缓存

```
第 1 次 message_to_audio → provider.tts_stream 被调用 1 次 → 写缓存
第 2 次 message_to_audio → provider 调用次数仍为 1（未增加）→ 直接回放 3 个块 + tts_end
```

⇒ 重复听不再计费。

### AC-03 换音色必须重新合成

key 里带了 `sha1(voice|model)` 指纹：

```
dashscope + longxiaochun_v3 → 命中
dashscope + longwan_v2     → 未命中 → 重新合成（calls=2），且音频内容与首次不同
```

⇒ 不会出现"换了音色还播旧声音"。

### AC-05 中断不写缓存

```python
gen = svc.message_to_audio(...)
next(gen)      # 只取第一个块
gen.close()    # 模拟客户端断开
```

结果：provider 已开始合成（calls 增加），但**缓存文件不存在**。
⇒ 半截音频不会进缓存，避免"播到一半突然结束"。

### AC-06 TTL 与损坏文件

| 场景 | 行为 |
|---|---|
| 把文件 mtime 改到 8 天前 | 下次请求判定过期 → 删除 → 重新合成 → 重建文件 |
| 往缓存文件写 `{ not json` | 下次请求解析失败 → 删除 → 重新合成 → 文件恢复合法 |
