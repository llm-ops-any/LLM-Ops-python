# CR-16102808 需求：代码节点沙箱化

- **需求性质**：增量（技术债）
- **类型**：技术债（只改内部实现，对外行为除「危险代码被拒」外不变）
- **来源**：`docs/待办.md` N2；代码自带 `todo:` 标记（`code_node.py:33`）

## 一、现状与问题

`CodeNode._execute_function` 当前是：

```python
local_vars = {}
exec(code, {}, local_vars)          # ← 在 API 进程内直接执行
return local_vars["main"](*args)
```

AST 只校验了「只能有一个 `main(params)` 函数、不能有其他语句」，**对函数体内做什么零限制**。

⇒ 任何能编辑工作流的人（或任何能调工作流 API 的凭证持有人），等于拿到：
- **任意代码执行**：`import os; os.system(...)`
- **读全部业务数据**：`open('/app/api/.env')` 拿到 `SQLALCHEMY_DATABASE_URI`、`JWT_SECRET_KEY`、各平台 API Key
- **拖垮服务**：`while True: pass` 占满 worker；`[0]*10**9` 吃光内存；fork 炸弹
- **横向移动**：读容器内的密钥后直连数据库

这不是"理论风险"——代码里作者自己写着「非常危险」。

## 二、目标（要达成的效果）

| # | 目标 |
|---|---|
| G-01 | 代码执行**必须离开 API 进程**：代码崩溃/死循环/内存爆炸不能影响主服务 |
| G-02 | 必须**限时**：超时强制终止，且连带子进程一起杀 |
| G-03 | 必须**限资源**：CPU 时间、内存、可写文件大小 |
| G-04 | 必须**断掉现成凭证**：子进程环境变量不得包含数据库连接串、JWT 密钥、平台 API Key |
| G-05 | 必须**拦住明显的危险动作**：读写任意文件、起子进程、开网络、动态导入 |
| G-06 | **不破坏现有用法**：已有工作流的 code 节点必须照常输出同样结果 |

## 三、不做（明确排除）

| # | 不做什么 | 原因 |
|---|---|---|
| 1 | 容器级强隔离（每节点起一个 Docker 容器 / Firecracker） | 需要挂 docker socket 或额外调度，**挂 socket 等于给容器 root，反而更危险**；当前单机课程环境收益不抵成本 |
| 2 | 用 `RestrictedPython` 之类库 | 需新依赖，且绕过手法多；不解决 CPU/内存耗尽 |
| 3 | 彻底防住「读文件系统」 | 需要 mount namespace / seccomp，容器内没权限；本 CR 用「清空环境变量 + 拦截 open/危险 import」缓解，**残留风险已在 `04-风险.md` 写明** |
| 4 | 给代码节点加网络白名单 | 现有代码不联网；真要用网络应走「API 工具」而不是脚本 |

## 四、验收标准

| AC | 内容 | 判定 |
|---|---|---|
| **AC-01** | 现有快递鸟工作流（`json/hashlib/base64`）输出与改造前**逐字段一致** | 改造前后各跑一次，比对 JSON |
| **AC-02** | `while True: pass` 在 **≤6 秒**内被终止，API 仍能正常响应其他请求 | 构造代码 + 并发 ping |
| **AC-03** | 分配大内存（`[0]*10**8`）被限制，容器不 OOM、`llmops-api` 不重启 | 构造代码 + 查容器状态 |
| **AC-04** | `import os` / `import subprocess` / `import socket` 被拒并给出可读原因 | 构造代码 |
| **AC-05** | `open('/app/api/.env')` 被拒；子进程内 `os.environ` 看不到 `SQLALCHEMY_DATABASE_URI` / `JWT_SECRET_KEY` | 构造代码打印环境 |
| **AC-06** | 向磁盘写文件被拒（`RLIMIT_FSIZE=0`） | 构造代码写 `/tmp/x` |
| **AC-07** | 原有校验错误提示不变（无 main、多个 main、main 参数不对、语法错、返回值非 dict） | 5 个用例 |
| **AC-08** | 单节点额外开销 **< 200ms** | 计时对比 |
