## 回滚

```bash
# 删 providers/pptx 目录 + providers.yaml 里的 pptx 块 + requirements 两个文件回滚
git checkout -- api/requirements.in api/requirements.txt \
  api/internal/core/tools/builtin_tools/providers/providers.yaml
rm -rf api/internal/core/tools/builtin_tools/providers/pptx
docker compose build llmops-api && docker compose up -d llmops-api llmops-celery && docker compose restart llmops-nginx
```

无数据影响；已生成的 COS 文件不会被删除（路径 `builtin-tools/markdown-to-pptx/`）。
