# 02-问题 · gradio-demo 跑不起来

## 1. 现象

原样执行 `python webui.py` 跑不通，且两个按钮的配置全部指向不可用资源。

## 2. 取证

### 2.1 依赖不全（U-01）

```
$ .venv\Scripts\python.exe webui.py
  File "webui.py", line 7, in <module>
    import requests
ModuleNotFoundError: No module named 'requests'
```

`requirements.txt` 原文只有 `python-dotenv==1.2.4` / `gradio==6.31.0` / `openai==3.41.0`，
但 `webui.py` 第 7 行 `import requests` —— **清单与实际 import 不一致**。

### 2.2 线上域名证书已过期

```
$ curl.exe -sS https://llmops.shortvar.com/api/openapi/chat
curl: (35) schannel: next InitializeSecurityContext failed: SEC_CERT_EXPIRED (0x80090328)
```

python `requests` 侧同样报 `SSLCertVerificationError: 证书不在有效期内`。
用 `verify=False` 能拿到 200（`{"code":"unauthorized",...}`），说明**是证书问题，不是网络或密钥问题**。
→ 这解释了「环境配置不对」的一半：`.env` 指着一条当前**必然失败**的线上地址。

### 2.3 线上密钥在本地库不存在

`.env` 里的 `LLMOPS_API_KEY` 是线上平台的密钥，打到本地 nginx 后返回：

```
{"code": "unauthorized", "message": "该秘钥不存在或未激活"}
```

本地库 `api_key` 表只有 2 条、都是 `llmops-v1/` 前缀，**与线上密钥不是一套**。

### 2.4 TTS 三条渠道全不可用

| 渠道 | 模型 | 实测结果 |
|---|---|---|
| 线上 `.env` 的中转 `api.nekoapi.com` | `tts-1` | `503 No available channel for model tts-1 under group auto (distributor)` |
| 公司中转 `token.uino.com/v1` | `tts-1` / `gpt-4o-mini-tts` / `qwen3-tts-flash` | `503 model_not_found`（32 个模型里 **没有任何** tts 类） |
| 阿里百炼 `dashscope` | `qwen3-tts-flash` / `cosyvoice-v2` / `cosyvoice-v3-flash` | `400 Arrearage`（账号欠费） |

补充探测结论（决定后端怎么写）：

1. 百炼 **OpenAI 兼容模式没有 `audio/speech`**：`POST https://dashscope.aliyuncs.com/compatible-mode/v1/audio/speech`
   → **404**（4 种 model/voice 组合全 404），所以不能照抄 OpenAI SDK 的 `client.audio.speech.create`；
2. 百炼 `GET /compatible-mode/v1/models` 里 tts 类只有 `qwen3-tts-flash`、`qwen3-tts-flash-realtime`；
3. `qwen-tts` 在原生接口返回 `404 InvalidParameter: Model not exist.`；
4. 原生接口 `POST /api/v1/services/aigc/multimodal-generation/generation` 认 `qwen3-tts-flash`，
   返回 `400 Arrearage` —— **模型名对、账单不对**。

## 3. 代码缺陷（U-03）

| # | 缺陷 | 后果 |
|---|---|---|
| 1 | `Path` / `uuid` 未 import | 只要点「转换为语音」就 `NameError` |
| 2 | `base_url=os.getenv("OPENAI_API_KEY")` | base_url 被填成密钥本身，SDK 直接抛 URL 非法 |
| 3 | `storage/audio/` 目录从未创建 | `stream_to_file` 写不进去（`FileNotFoundError`） |
| 4 | 失败时 `return "语音生成失败：…"`，但 `outputs` 是 `gr.Audio` | gradio 把错误文本当文件路径去 hash：`OSError: [Errno 22] Invalid argument: '…语音生成失败：…'`，请求整体失败、原因被吞 |

第 4 条最坑：错误信息本身成了**文件路径**，前端只看到「应用异常」，看不到真实原因。

## 4. 根因

```
requirements.txt 漏 requests            → 启动即崩
.env = 线上地址(证书过期) + 线上密钥     → 「获取文案」必然 unauthorized / SSL 失败
TTS 用 OpenAI tts-1 + alloy             → 中转站无渠道、百炼无此模型
3 处 import/目录/bug + 1 处错误返回类型  → TTS 链路就算有额度也跑崩
```
