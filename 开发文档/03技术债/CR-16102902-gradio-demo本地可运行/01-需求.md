# 01-需求 · gradio-demo 本地可运行

## 1. 背景

`gradio-demo/` 是一个独立演示工程（从 `echoMimic/webgui.py` 裁出来的最小版）：左侧「文案主题 → 获取文案」，
下方「转换为语音」，右侧留视频位。目录内只有 `webui.py`、`requirements.txt`、`.env.example`，**无 `.env`、无虚拟环境**。

## 2. PO 要求（原话）

1. 「安装易(依赖)来运行一下」——要能在本机跑起来；
2. 「环境配置都不对，换成本地可用的配置」——不要线上地址 + 不匹配的密钥；
3. 「`model="tts-1"` 这个模型也不可用，咱们有阿里百炼的可以用」——TTS 换百炼。

## 3. 功能需求（FR）

| 编号 | 需求 |
|---|---|
| FR-01 | `pip install -r requirements.txt` 后可直接启动，依赖清单与实际 import **完全一致** |
| FR-02 | `.env` 指向**本地** LLMOps 平台（经 nginx `:80`），应用 id 与开放 API 密钥取自本地库，开箱可用 |
| FR-03 | 「获取文案」调用本地 `/api/openapi/chat`，把 `data.answer` 回填到文案框 |
| FR-04 | 「转换为语音」调用**阿里百炼** TTS，模型/音色/地址可由 `.env` 覆盖，不再出现 `tts-1` / `alloy` |
| FR-05 | 失败要**弹窗提示**，不能把错误字符串当文件路径交给 `gr.Audio` 导致整个请求崩掉 |

## 4. 验收标准（AC）

| 编号 | 标准 | 状态 |
|---|---|---|
| AC-01 | `.venv` 全新安装 `requirements.txt` 无 `ModuleNotFoundError` | 通过 |
| AC-02 | 服务启动，`http://127.0.0.1:7860` 可访问，日志无异常 | 通过 |
| AC-03 | 「获取文案」走**本地 nginx** 返回真实文案（非 mock、非线上域名） | 通过 |
| AC-04 | ⚠️ 「转换为语音」能生成 mp3 并播放 | **未通过（外部阻塞：百炼欠费）** |
| AC-05 | TTS 失败时前端弹窗显示原因，服务端不抛 `OSError` | 通过（实测弹窗内容为 `百炼返回 400：Arrearage…`） |
| AC-06 | `.env.example` 与真实配置键一致，注明「百炼不是 OpenAI 兼容 `audio/speech`」 | 通过 |
