# 文档结构

> 布局由 AIDLC 技能第 E 节规定，**唯一一套**，不在本项目另行设计。
> **核心原则：一条 CR 的所有内容都在它自己的目录里；跨 CR 的视图本地生成、不入库。**
> 用法：整份复制到 `开发文档/00规则/文档结构.md`，只补最后一节「本项目补充」，上面三节原样保留。

## 一、目录布局

```text
开发文档/
├── 00规则/      项目概述.md  团队配置.md  协作规范.md  开发规范.md  文档结构.md
├── 01需求/      CR-<8位号>-<简称>/        # 需求：用户能感知的新行为（停 G1）
├── 02缺陷/      CR-<8位号>-<简称>/        # 缺陷：与已批准预期不符（不停 G1）
├── 03技术债/    CR-<8位号>-<简称>/        # 技术债：只改内部实现（停 G1）
│   └── CR-<8位号>-<简称>/                 # ← 一条 CR 一个目录，自包含（目录名就是号）
│       ├── 需求.md          # 需求正文 + FR/AC 号段（唯一来源）
│       ├── 状态.md          # 创建 / 更新 / 阶段 / 门禁 / 下一步
│       ├── 设计/            # 应用设计 / 代码结构 / 工作单元 / 业务规则
│       ├── 测试记录.md      构建说明.md      验收报告.md      问题.md
│       ├── 运维说明.md      # 只有部署类 CR 才有
│       ├── 变更说明.md      # 对项目级事实的影响（交付 / 存储 / 规模）
│       ├── 决策记录.md      # **为什么这么做**：选型对比 / 被否方案 / 决策人
│       ├── 前置资源.md      # **能不能做**：缺了做不了的东西，G1 前必须列
│       ├── 风险.md          # **可能怎么失败**：可能性 / 影响 / 触发信号 / 应对
│       ├── 证据/            # 截图 / 录屏 / 样本（单文件 ≤ 5 MB，更大走 LFS）
│       └── 审计-<人>.md     # 审计跟着 CR 走，一人一份，只追加
├── 04技能/      aidlc 副本（66 文件，含 scripts/；**全仓库只此一份**，子项目不再各存一份）
└── _汇总/                    # ⚙ 本地生成、**不入库**（.gitignore 排除）
    ├── 状态.md  需求索引.md  当前需求全貌.md  技术设计.md
    ├── 运维说明.md  项目现状.md  决策记录.md  风险与资源.md  审计视图.md
    ├── index.html  _sidebar.md  vendor/  docs/  如何预览.txt
```

**没有独立的设计 / 测试 / 运维 / 审计目录** —— 它们的内容都按 CR 拆进了
`CR-XXXX/`，全局视图由 `汇总.py` 合成到 `_汇总/`。这样两条 CR 并行时落在互不相交的路径上，**文档零冲突**。

> 为什么布局要写死：允许「项目自定义布局」＝ 工具和文档各认一套，`汇总.py` 会直接报
> 「没有可汇总的需求目录」。**布局只有一套，代码和文档才不会打架。**

## 二、判定规则（一个文件该放哪）

三步判定，**没有第四步**：

1. **规则 / 共识（不随 CR 变）** → `00规则/`
2. **属于某一条 CR** → `<类型目录>/CR-XXXX-<简称>/`（目录名就是号，取号 = 建目录）
3. **跨 CR 的汇总视图** → **不手写**，跑 `scripts/汇总.py` 生成到 `_汇总/`

**不存在「跨需求且持续更新」的手写文件** —— 那类内容按 CR 拆开，全局视图由脚本合成。

## 三、生成物（本地生成、不入库）

| 视图 | 由哪些分片合成 |
|---|---|
| `状态.md` | 各 `CR-XXXX/状态.md` |
| `需求索引.md` | 各 `CR-XXXX/需求.md` 头部字段（含 `需求性质`） |
| `当前需求全貌.md` | **基线 + 各增量**的 `需求.md` 正文，按编号排序拼接 |
| `技术设计.md` | 各 `CR-XXXX/设计/*.md` |
| `运维说明.md` | 各 `CR-XXXX/运维说明.md` |
| `项目现状.md` | 各 `CR-XXXX/变更说明.md` |
| `决策记录.md` | 各 `CR-XXXX/决策记录.md` |
| `风险与资源.md` | 各 `CR-XXXX/{风险,前置资源}.md` —— **开工前和交付前的检查单** |
| `审计视图.md` | 各 `CR-XXXX/审计-<人>.md` |

整目录 `.gitignore` 排除（`安装钩子.py` 会补上）。开工先跑一次再读，否则读到的是过期表格。
