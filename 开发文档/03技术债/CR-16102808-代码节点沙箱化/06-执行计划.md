# CR-16102808 执行计划

## 一、工作单元

| 单元 | 内容 | 文件 | 判据 |
|---|---|---|---|
| **U-01** 子进程执行体 | 读 stdin（code+params）→ 受控 exec → 调 main → 结果写 stdout（JSON），stdout 重定向防污染 | `internal/core/workflow/nodes/code/sandbox_runner.py`（新增） | 独立可运行 |
| **U-02** 主进程改造 | AST 白名单校验 + subprocess 调用 + setrlimit + env 净化 + 超时 killpg | `internal/core/workflow/nodes/code/code_node.py` | AC-01~AC-08 |
| **U-03** 测试脚本 | 覆盖正常/越权/超时/内存/写盘/环境变量 6 类 | `api/test/manual/workflow-sandbox/` | 全绿 |

## 二、顺序

```text
U-01 runner → U-02 主进程改造 → 语法校验 → 构建 api 镜像 → 部署
→ 用现有工作流的真实代码验 AC-01（输出一致）
→ AC-02~AC-07 逐个构造验证 → AC-08 计时 → 文档
```

## 三、验证方法

所有测试在容器内跑脚本（不经过前端），直接调 `CodeNode._execute_function`：

```python
from internal.core.workflow.nodes.code.code_node import CodeNode
CodeNode._execute_function(code, params={"a": 1})
```

| AC | 用例 |
|---|---|
| AC-01 | 取库里真实代码（快递鸟签名），改前改后各跑一次比对 dict |
| AC-02 | `def main(params):\n    while True:\n        pass` |
| AC-03 | `def main(params):\n    x = [0] * (10**8)\n    return {"n": len(x)}` |
| AC-04 | `def main(params):\n    import os\n    return {}` |
| AC-05 | `def main(params):\n    import os\n    return {"env": dict(os.environ)}`（应被 import 拦截；另跑一条只用 `__builtins__` 的探针看能否读 env） |
| AC-06 | 写 `/tmp/x`（应被 FSIZE 拦或 open 拦） |
| AC-07 | 无 main / 两个 main / 参数错 / 语法错 / 返回非 dict |
| AC-08 | 同一段代码执行 20 次取平均，对比改造前 |

## 四、回滚

单文件改动（`code_node.py`）+ 一个新文件。回滚 = `git revert` 该提交，无数据/依赖影响。

## 五、兼容性核对（上线前必做）
