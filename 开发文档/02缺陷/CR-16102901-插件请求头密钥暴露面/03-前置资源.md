## 代码入口（读取链路，决定"解密要放在哪"）

```
对话 → app_config_service.get_draft_app_config / get_app_config
      → ToolEntity(headers=api_tool.provider.headers)      ← 必须解密
      → api_provider_manager.get_tool → tool_func(headers)  → 上游 HTTP
工作流 → workflow/nodes/tool/tool_node.py
      → ToolEntity(headers=api_tool.provider.headers)      ← 必须解密
接口   → api_tool_schema 三处 Resp                          ← 必须脱敏
```

结论：解密收口在 `ApiToolProvider.decrypted_headers`，脱敏收口在 `mask_headers`，两条出口各只有一个。
