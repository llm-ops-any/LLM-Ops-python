## 回滚

```bash
git revert <commit> && docker compose build llmops-api && docker compose up -d llmops-api
docker compose restart llmops-nginx
```

## 调参入口

都在 `code_node.py` 模块顶部，改完重建即可：

| 常量 | 现值 | 说明 |
|---|---|---|
| `SANDBOX_TIMEOUT` | 5（秒） | 墙钟超时 |
| `SANDBOX_ALLOWED_MODULES` | 32 个 | 模块白名单，加模块只改这里 + `sandbox_runner.SAFE_MODULES` |
| `SANDBOX_FORBIDDEN_CALLS` | 12 个 | 禁止调用的内置函数 |
| `SANDBOX_ENV` | 4 个变量 | 子进程可见的环境变量 |

`sandbox_runner.py` 顶部另有一组资源上限（`LIMIT_CPU_SECONDS` / `LIMIT_AS_BYTES` / `LIMIT_FSIZE_BYTES` / `LIMIT_NOFILE`）。

> ⚠️ **两处白名单要同步**：`code_node.SANDBOX_ALLOWED_MODULES` 和 `sandbox_runner.SAFE_MODULES`。
> 前者给用户可读错误，后者是真正的兜底。只改一处会出现「AST 放过、runner 仍拒」的不一致。
